# MisskeyCssMapper

Misskey のビルド済み CSS に含まれるクラス名を、CSS 宣言から生成した読みやすい名前に置き換えます。`MkSwitch` の既知の構造は `switchBox` などの名前を保持し、それ以外のクラスも位置・レイアウト・見た目の宣言をもとに `mk...` 形式の名前を自動生成します。

## 使い方

1. 対象の Misskey CSS を `css/` に置きます。
2. `npm run build` を実行します。
3. 変換後の CSS は `patched_css/`、元クラス名と変換名の対応表は `patched_css/<ファイル名>.mapping.json` に出力されます。

CSS の宣言だけから元 Vue コンポーネントの正確なクラス名を復元することはできないため、一般クラス名は宣言内容を表す自動生成名です。対応表を使って変換結果を元クラス名と照合できます。
